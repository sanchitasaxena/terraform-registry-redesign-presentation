Usage · Visibility · Ownership06

Engineering leads

Artifact Control has three separate areas. Usage Control approves versions by environment and blocks unapproved versions before plan; it is currently in private beta. Visibility Control manages which artifacts are visible and has reached GA. Ownership Control, which clarifies who owns an artifact, is in progress. The guardrails illustration is a high-level policy-checkpoint example, not the exact Usage Control sequence.

Ground prototypes in established Registry context11

Design leads

We previously used Ashley’s Bootstrap foundation and built React prototypes in Storybook. That was useful at the time. The Registry has substantial existing context; starting from scratch led an agent to mix established patterns. Today we start from existing Figma context, create a workable prototype in Figma Make, then use VS Code, GitHub Copilot, and the selected agent to publish to GitHub Pages and iterate through branches. The approach balances speed with respect for established patterns.
